# 전수 검사에서 실제로 나온 것 (데모 20종)

> 대상: 아라. 2026-09-16~17 에 「기업 랜딩 10종」과 「쇼핑몰·커머스 10종」을 전수로 재고 고친 기록.
> 규칙을 나열한 문서가 아니라 **누나가 만든 화면에서 실제로 나온 것**을 모았다. 같은 모양이 계속 반복돼서다.
> 입고 규격은 `docs/PORTFOLIO_FACTORY.md` §0 에 있고, 이 문서는 「왜 그 규칙이 생겼는가」에 해당한다.

먼저 — 하루에 15종씩 뽑아낸 건 정말 대단한 속도다. 아래는 그 속도를 깎자는 게 아니라,
**같은 실수를 기계가 대신 잡게 해서 누나가 디자인에만 집중하게** 하려는 정리다.

## 2. 이제 **기계가 막아 준다** — 외우지 않아도 되는 것

`node scripts/audit-portfolio.mjs` 가 ERROR 를 내면 입고가 막힌다. 아래는 전부 자동으로 잡힌다.

- **지어낸 식별번호** — 사업자등록번호 · 통신판매업신고 · 종목코드 · 인증번호 · 면허 · DOI
- **실존 기업·기관·매체·브랜드 이름** (명품 하우스 · 국내 커머스 플랫폼 · 반도체/발사체 기업 · 인증단체 · 언론사 포함)
- **실존 제품 라인명** (RTX 4080 · Core Ultra 9 류)
- **가짜 접수** — 「접수되었습니다」 · 주문번호 · 운송장 · `SampleNotice` 미연결 폼
- **최상급·단정** — 1위 · 최초 · 100% · 무결점 · 보장
- **이미지 크기** — 긴 변 1024px 미만이면 경고(로고·아이콘·가로 띠는 자동 제외)
- **게이트 밖 자산** — 데모를 내려도 남는 자리에 파일을 두면 ERROR
- **홈 카드 문구**(`galleryData.ts`) — 2026-09-17 부터 ERROR

**올리기 전에 이 한 줄만 돌리면 된다.**

```
node scripts/audit-portfolio.mjs
```

## 3. 기계가 **못 잡는 것** — 여기만 사람이 조심하면 된다

정직성 쪽은 이제 대부분 자동이다. 남은 위험은 전부 **「눌렀을 때」** 쪽이고, 검사기가 구조상 볼 수 없다.

### ① 눌러도 아무 일도 일어나지 않는 것
가장 많이 나왔다. 영업 상대가 제일 먼저 누르는 자리라 바로 들통난다.
- `href="#"` 165건 (노르딕 피크 16 · 베르데 고메 12 · 메종 드 럭스 10 · 아틀라스 8 …)
- **필터 칩이 아무 동작도 안 함** — 테크노바 「하드웨어 분류」 5종은 `filters.segment` 를 읽는 코드가 저장소에 아예 없었다. 누르면 파랗게 켜지고 「[선택]」까지 붙는데 결과는 그대로.
- **필터가 언제 눌러도 결과 0건** — 노르딕 피크 3개, 루미너스 랩 3개. 상품이 4종인데 칩이 그보다 넓게 깔려 있었다.
- 넥서스 상담 위저드의 단계 표시기가 **고정 장식** — 끝까지 입력해도 영원히 「1단계」.

👉 **만들 때 기준**: 화면에 단추를 놓았으면 **누른 결과가 반드시 달라져야** 한다. 갈 곳이 없으면 그 단추를 만들지 않는 쪽이 낫다.

### ② 무엇을 눌러도 같은 내용이 뜨는 모달
- 넥서스 — 로봇 3종(AMR-500/1500/3000) 사양서가 **제목만** 다르고 내용이 동일. 모델별 제원은 데이터에 다 있었는데 모달로 전달이 안 됐다.
- 트랜스오션 — 화물을 바꿔 눌러도 센서 값이 고정(-18.2℃ · 42.4% RH). 바로 옆 카드 수치와 정면으로 모순.
- 메종 아키텍트 — 히어로 핫스팟 3개(소파·조명·테이블)가 전부 같은 번들 드로어. 조명을 눌렀는데 3종이 담겼다.

👉 **기준**: 선택한 것이 모달 **본문**까지 내려가는지 한 번만 눌러 보면 보인다.

### ③ 데이터끼리 어긋나는 것
- 아틀라스 — 목적지 「교토」에 대응 빌라가 **0개**. 교토를 고르면 남해·제주 빌라가 붙은 채 요금만 1.25배.
- 메종 드 럭스 — 간판 기능인 **로트 번호 조회**에 정작 팔고 있는 상품이 하나도 안 걸렸다.
- 테크노바 — 같은 모델 가격이 한 지면에 **두 개**(히어로 ₩3,490,000 / 매트릭스 ₩2,890,000, 주문서는 또 다름).
- 메종 아키텍트 — 커피 테이블 상품이 「모듈 소파」로, 조명 이름은 플로어 스탠드인데 부제는 펜던트.
- 트랜스오션 — 「3일 14시간 남음」이라면서 도착 예정일이 **2025년 5월**(지금은 2026년 9월).

### ④ 도달 불가능한 코드가 살아 있는 것
노르딕 피크 `OrderModal.tsx` 에 **가짜 주문완료 화면**(「배송이 시작되었습니다」 · 송장번호)이 그대로 있었다. `setIsSubmitted(true)` 호출이 0회라 지금은 안 뜨지만, **한 줄만 이으면 금지 규칙을 정면 위반하는 화면이 켜진다.**

👉 **기준**: 안 쓰는 화면은 남기지 말고 지운다.

### ⑤ 데모에 없는 기능을 카드가 광고하는 것
루미너스 랩 — 데모는 의도적으로 「자체 클린 등급 · 공인 인증 아님」으로 만들어 뒀는데, **홈 카드만** 「EWG 그린 등급 검사기」라고 팔고 있었다. 카드는 **데모 실물 그대로** 적어야 한다.

### ⑥ 금지어만 지우고 개념은 남기는 것
「에스크로」가 금지어라 그 낱말만 지우고 **「안심 예치 결제」**로 바꾼 자리가 5종에 퍼져 있었다(파일명은 `EscrowModal.tsx` 그대로). **결제대금예치는 전자상거래법상 규제 용어**라 표현을 바꿔도 무게가 같다.

👉 **기준**: 낱말이 아니라 **주장**을 지운다.

## 4. 업종별로 특히 조심할 것

지어낸 브랜드라도 **업종에 따라 법이 따라온다.** 고객이 이 템플릿을 그대로 받아 쓰면 **그 사람이 위법한 페이지를 띄우게 된다.**

| 업종 | 조심할 것 | 실제 사례 |
|---|---|---|
| 반려동물 사료 | 질병의 예방·치료 효능 표방 금지(사료관리법) | 포우즈 앤 테일 후기 「슬개골 탈구 2기 호전」·「스트루바이트 결석」 |
| 화장품 | 의약품 오인 효능 금지(화장품법 제13조) · 「실구매 인증」 주장 | 루미너스 랩 |
| 명품·중고거래 | 「정품 인증」·「공인 감정」은 그 회사만 할 수 있다 | 메종 드 럭스 「에르메스·샤넬 공인 감정위원」 |
| 식품 | 정부 공인 등급을 단정하지 않기 | 베르데 고메 「1++ No.9 최고 등급」 |
| 의료 | **의료광고법** — 다음 배치에서 가장 위험할 것으로 본다 | (아직 검사 전) |

## 5. 다음 배치에서 이것만

1. 올리기 전 `node scripts/audit-portfolio.mjs` **ERROR 0** (홈 카드 문구도 이제 여기서 함께 본다)
2. **단추를 놓았으면 누른 결과가 달라지는지** 한 번 눌러 보기
3. **선택한 것이 모달 본문까지** 내려가는지 확인
4. 안 쓰는 화면·코드는 지우기
5. 카드 문구는 **데모 실물 그대로**

1번은 기계가, 2~5번은 누나만 볼 수 있다. 이 다섯 줄이면 내가 뒤에서 할 일이 거의 없어진다.
